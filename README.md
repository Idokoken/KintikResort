#  Kintik Resort Website

## Usage
This is a website showing the service offered by Kintik Resort and for making reservation on the Resort.

## Description

Kintik Resort is a responsive web application designed to facilitate seamless reservation on the Resort. Built with React,  Kintik Resort offers a user-friendly interface, and efficient and seamless reservation.

## Technology used

The technologies used for developing the website includes
1. React(Javascript)
2. CSS
3. Bootstrap Framework
4. Some external dependencies like styled-component, react-router-dom, slick-carousel etc.


The hosted(live) website can be viewed on **[https://kintikresort.com.ng](https://kintikresort.com.ng)**.
